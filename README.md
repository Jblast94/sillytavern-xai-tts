# SillyTavern xAI TTS Extension

Native xAI Text-to-Speech integration for SillyTavern (voices: Eve, Ara, Leo, Rex, Sal).

**Features**
- Full support for xAI speech tags (`[laugh]`, `<whisper>text</whisper>`, `<slow>`, etc.)
- Follows current SillyTavern TTS provider template
- Browser-based (no extra Docker container or networking issues)

**Setup**
1. Get your xAI API key from https://console.x.ai
2. Install this extension via Git in SillyTavern
3. Enter your key in the extension settings
4. Select "xAI" in the main TTS extension

Created for easy one-click install.
